# Customer Segmentation using K-Means Clustering

This project demonstrates unsupervised machine learning using the K-Means clustering algorithm. Customer data is preprocessed using StandardScaler, and the Elbow Method is used to determine the optimal number of clusters. The model groups customers based on similar characteristics, and the results are visualized using scatter plots and cluster centers.

## Key Concepts

* Unsupervised Learning
* K-Means Clustering
* Data Preprocessing and Scaling
* Inertia
* Elbow Method
* Cluster Visualization

## Project Workflow

1. Generate or load customer data.
2. Scale the features using StandardScaler.
3. Use the Elbow Method to find the optimal number of clusters.
4. Train a K-Means model.
5. Visualize customer segments and cluster centers.
6. Interpret the discovered customer groups.

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-Learn

## Learning Outcome

This project helps understand how K-Means clustering discovers hidden patterns in unlabeled data and how clustering can be used for customer segmentation and exploratory data analysis.
